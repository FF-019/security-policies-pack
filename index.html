About this project. Built as a practical GRC portfolio piece: four core policies written in the structure used by large organizations (purpose, scope, numbered statements, roles, exceptions, enforcement, review), then traced to recognized control frameworks so each requirement can be audited. The interactive tools show how each policy is operated day to day.
