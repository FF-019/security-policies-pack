# Security Policies Pack

Policy workspace for four core information security policies: Access Control, Data Classification, Incident Response and Risk Management.

Live: https://ff-019.github.io/security-policies-pack/

## Contents

- **Policies**: controlled documents with purpose, scope, numbered statements, RACI, exceptions and review cycle
- **Control library**: 26 statements mapped to NCA ECC-2:2024, ISO/IEC 27001:2022 and NIST CSF 2.0 (88 mappings)
- **Risk register**: 5×5 likelihood × impact scoring with heat map and treatment plans
- **Evidence**: audit evidence and implementation status per control
- **Incident drill**: phishing case walked through the response phases and deadlines
- **Access review**: quarterly certification checked against the access control policy
- **Data handling**: classification labels and handling rules

Static site, no build step. Open `index.html`.
