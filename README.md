# Security Policies Pack

An enterprise security policy set covering four core areas of Governance, Risk & Compliance:

| Code | Policy | Statements |
|---|---|---|
| POL-AC | Access Control | AC-01 … AC-07 |
| POL-DC | Data Classification | DC-01 … DC-06 |
| POL-IR | Incident Response | IR-01 … IR-07 |
| POL-RM | Risk Management | RM-01 … RM-06 |

Each policy follows the structure used in large organizations: purpose, scope, numbered statements, RACI, scenario, measures of effectiveness, tooling, exceptions and enforcement.

**Traceability.** Every statement is mapped to:
- Saudi NCA Essential Cybersecurity Controls (ECC-2:2024)
- ISO/IEC 27001:2022 (Annex A and clauses)
- NIST Cybersecurity Framework 2.0

**Compliance posture** with implementation status and audit evidence for every statement.

**Interactive tools** that show how each policy is operated:
- Risk heat map and register (5×5 likelihood × impact)
- Quarterly access review with policy findings
- Incident response clock with deadline checks per phase
- Data classification helper with handling rules

**Live:** https://ff-019.github.io/security-policies-pack/

Framework mappings are the author's interpretation of the public control catalogs.
